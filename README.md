# THUSA SMALL BIZ - Mogopela Youth Marketplace
Founder: Lorato Sabole | Mahikeng / Mogopela Village

### The Problem
Youth in Mogopela have skills but no customers. Baker wastes cakes, hairdresser no bookings, farmer morogo rots.

### The Solution
THUSA - One WhatsApp number to order all:
- WhatsApp Bot: Order Muffin P5, Tray Cake P80
- USSD: *120*123# for no-data users  
- Flutter App + Google Maps for delivery
- FNB eWallet for payments
- Firebase backend

### Products (Live)
1. Muffin - P5 each
2. Tray Cake P80 (12 pcs) - Bestseller for parties
3. Braids - P50
4. Morogo Bundle - P20

### Impact
3 youth employed, 20 customers weekly, P2000 monthly income.

Built for Sonke Youth Entrepreneurship Competition 2026
